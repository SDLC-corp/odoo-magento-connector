Core workflows

A connector built for day-to-day operations

Orders and customers

Import Magento orders and customer accounts, keep source identifiers, and apply configurable order, tax, payment and carrier mappings.

Products and categories

Synchronize categories, attribute sets, attributes, images and simple, virtual, downloadable, configurable, bundle and grouped products.

Inventory and MSI

Map Odoo warehouses and locations to Magento Multi-Source Inventory sources and push stock changes through controlled jobs.

Invoices and fulfilment

Send invoices, shipments and tracking details to Magento and import credit memos with idempotent document handling.

Pricing and store views

Manage price export rules, tier prices, websites, store groups, store views, languages, currencies and localized product content.

Queue and recovery

Process large data sets in bounded jobs with retry controls, incremental watermarks, sync reports, conflict tracking and an error center.

Guided configuration

Connect safely, then choose what to synchronize

The setup flow validates the store address and API access, discovers store views, proposes mappings and keeps credentials restricted to Magento administrators.

Each instance can use bearer-token or OAuth 1.0 authentication, company isolation, SSL verification, automatic schedules and a selectable synchronization scope.

Traceable commerce documents

Magento references, store context and synchronization state stay visible on the related Odoo sales, invoice and delivery records.

Actionable exception handling

Classify failures, inspect the affected entity and instance, retry recoverable work and keep an auditable resolution history.

Requirements

Know what is needed before installation

Odoo

Odoo 19 Community or Enterprise with Sales, Inventory and Invoicing installed. This is a server module and is not compatible with Odoo Online.

Magento

Magento Open Source or Adobe Commerce 2.4.6–2.4.9 with HTTPS access to the REST API and an integration account with permissions for the selected features.

Operations

Odoo cron must run for schedules and queues. Near-real-time push additionally needs the compatible Magento companion extension, Magento cron and an HTTPS-reachable Odoo endpoint.
