Data Flow

Import & Export Operations

Granular control over every data entity flowing between your ERP and storefront.

↓ Import

Magento → Odoo

  • Sync orders in real-time or via scheduled batch transfer for data-heavy flows
  • Import payments along with full Magento payment method metadata
  • Import Products and Variants with Magento-specific attribute details
  • Import Product Information, Pricing, & Taxes with cross-reference mapping
  • Create and maintain Magento Product Websites references inside Odoo
  • Import shipping companies from Magento and associate them in Odoo
↑ Export

Odoo → Magento

  • Publish orders from Odoo to Magento as completed sales with full line items
  • Export invoices along with payment status back to Magento
  • Export Products (simple, configurable, bundled) with Magento attribute mapping
  • Export Order Status, Shipping Details, and Tracking Number references
  • Create shipments in Magento from Odoo delivery confirmations automatically
  • Manage stock levels and push live inventory updates to Magento in real-time
